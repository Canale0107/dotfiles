# tmux 操作マニュアル

この設定 (`.tmux.conf`) での操作方法まとめ。

## Prefix キー

デフォルトの `Ctrl-b` ではなく **`Ctrl-a`** に変更済み。以下の操作はすべて
「Prefix (`Ctrl-a`) を押してから離し、次のキーを押す」という意味。

`Ctrl-a` 自体をターミナルにそのまま送りたい場合は `Ctrl-a` を2回押す
（`Ctrl-a` → `Ctrl-a`）。

## ペイン（画面分割）

| キー | 動作 |
| --- | --- |
| `Prefix` → `v` | 縦に分割（左右に並べる） |
| `Prefix` → `s` | 横に分割（上下に並べる） |
| `Prefix` → `h` / `j` / `k` / `l` | ペイン移動（Vim風: 左/下/上/右） |
| `Prefix` → `H` / `J` / `K` / `L` | ペインリサイズ（連打可、1列ずつ） |

## コピーモード（Vimキーバインド）

`setw -g mode-keys vi` により、コピーモード内は Vim ライクな操作になる。

| キー | 動作 |
| --- | --- |
| `Prefix` → `[` | コピーモードに入る |
| `h` / `j` / `k` / `l` | カーソル移動 |
| `v` | 選択開始（ビジュアルモード） |
| `y` | 選択範囲をコピーしてコピーモードを抜ける |
| `q` | コピーモードを抜ける |

## その他の基本操作

| キー | 動作 |
| --- | --- |
| `Prefix` → `c` | 新しいウィンドウを作成 |
| `Prefix` → `n` / `p` | 次/前のウィンドウへ移動 |
| `Prefix` → `0`〜`9` | 番号のウィンドウへ移動（`base-index 1`のため1始まり） |
| `Prefix` → `d` | セッションから切り離す（デタッチ） |
| `Prefix` → `x` | 現在のペインを閉じる（確認あり） |
| マウス操作 | `mouse on` によりクリックでペイン選択、ドラッグでリサイズ、ホイールでスクロール可能 |

## セッション操作（プレフィックス不要）

| コマンド | 動作 |
| --- | --- |
| `tmux new -s <名前>` | 名前付きセッションを新規作成 |
| `tmux ls` | セッション一覧を表示 |
| `tmux attach -t <名前>` | セッションに再接続 |
| `tmux kill-session -t <名前>` | セッションを終了 |

## 設定のリロード

設定ファイルを編集した後は、tmux内で以下を実行:

```text
Prefix → :
source-file ~/.tmux.conf
```

## ステータスバー

左下に現在のセッション名、右下に日時を表示するだけのシンプルな構成
（`status-left` / `status-right`）。
